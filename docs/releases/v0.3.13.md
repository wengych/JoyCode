# JoyCode 0.3.13 — Early Preview

Build 25。本版是 SDK 编译兼容性补丁，不改变手柄功能或 macOS 14 最低要求。

## 修复

首次 `macos-15` CI 因部分 Accessibility Swift 常量名称在该 SDK 中不可用而编译失败。本版改为已核对的相同 AX 协议字符串，保留原搜索参数和行为。

本地 198 项自动测试、打包及签名校验通过。发布流水线在远端测试、构建和校验成功后才创建 Release；执行记录见 [Actions](https://github.com/wengych/JoyCode/actions)。

## 验证边界与已知问题

- Codex 原生 X 开始／X 结束、X 开始／B 取消、LB／RB 切换及重入的实体验收来自 **0.3.12**，本补丁没有重新进行实体全键验收。
- **Codex 右摇杆滚动的最新实体测试失败，本版未修复。**
- **Codex A 提交尚未获得实体结果确认。**Claude 的较完整实体成功记录也属于早期版本。
- 滚动可能移动真实鼠标指针；进入转写阶段后需在 Agent 内手动取消。
- 应用仍使用本地 ad-hoc 签名，未经 Apple notarization；Bundle ID 保持 `local.weng.XboxAgentRemote`。

需要 macOS 14 或更新版本、Xbox 手柄及已适配的桌面客户端。解压应用后授予辅助功能权限，并在 JoyCode 中启用控制。

发布附件为应用 ZIP 与 `SHA256SUMS`，将两者放在同一目录后校验：

```bash
shasum -a 256 -c SHA256SUMS
```

完整说明见 [README](https://github.com/wengych/JoyCode/blob/v0.3.13/README.md) 和 [CHANGELOG](https://github.com/wengych/JoyCode/blob/v0.3.13/CHANGELOG.md)。
