# JoyCode 0.3.12 — Early Preview

用 Xbox 手柄控制 macOS 上的 Claude 和 Codex：肩键切换应用，X 开始／结束听写，B 取消录音，A 检查后提交草稿，方向键切换会话。

这是 build 24 的早期预览版，**Codex 右摇杆滚动仍有已知故障**。

## 本轮改进

- 修复 Codex 取消听写后编辑器重建导致的状态锁定，统一 LB／RB 的恢复行为。
- 完善停用、断连、手动复位及异步任务清理，避免旧任务覆盖新状态。
- 增加每目标提交尝试记录，防止结果未知时重复提交同一草稿。
- 普通动作持续核对前台应用与原窗口；只有明确的激活操作能切换应用。

## 已验证与未完成

- 198 项自动测试、发布构建和签名校验通过。
- Codex 原生听写开始／结束、开始／取消、LB／RB 切换及重入已通过实体手柄验证，取消与切换连续两轮通过。
- **Codex 右摇杆滚动最新测试失败，尚未修复。**
- **Codex A 提交尚未确认**，不能由组合测试中的滚动反馈推断成功。
- Claude 的历史版本已有语音、提交与导航成功记录，当前版本尚未完成全键复测。

## 使用须知

需要 macOS 14 或更新版本、Xbox 手柄及已适配的桌面客户端；目前主要在 Apple Silicon 上验证。解压后打开 JoyCode，并在系统设置中授予辅助功能权限，然后启用控制。

优先使用 Agent 原生听写，Typeless 为可选后端。听写完成后先检查草稿，再按 A；进入转写阶段后，取消需在 Agent 内手动操作。滚动可能移动真实鼠标指针。

应用使用本地 ad-hoc 签名，**未经 Apple notarization**。内部 Bundle ID 保持 `local.weng.XboxAgentRemote`，以兼容早期配置。

发布附件包含应用 ZIP 与 `SHA256SUMS`。将两者下载到同一目录后，可执行：

```bash
shasum -a 256 -c SHA256SUMS
```
