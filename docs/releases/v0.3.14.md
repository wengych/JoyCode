# JoyCode 0.3.14 — Early Preview

Build 26。本版增加手柄电量提示，不新增弹窗，不改变遥控状态机。

## 新增

- 菜单栏 JoyCode 手柄图标旁显示电池填充条，菜单和设置窗口显示详细电量。
- 充电时显示闪电；电量不高于 20% 且未充电、也非已充满状态时显示低电量标记。
- 每 30 秒通过原生 GameController 刷新，暂停遥控后仍会更新。
- 未连接手柄时隐藏电量条；未上报电量或值无效时显示未知，不当作 0%。百分比是系统／手柄上报的估计值。

本地 205 项自动测试、各电量状态的渲染样图检查及安装包构建、签名、SHA-256 校验通过。远端构建与发布结果见 [Actions](https://github.com/wengych/JoyCode/actions)。

## 验证边界与已知问题

- 运行中的 0.3.14 已确认未连接手柄的界面状态；真实电量、充电上报及连接后的实体显示尚未验收。渲染样图通过不代表手柄电量上报已验证。
- Codex 原生 X 开始／X 结束、X 开始／B 取消、LB／RB 切换及重入的实体验收来自 **0.3.12**，本版尚未重新进行实体全键验收。
- **Codex 右摇杆滚动的最新实体测试失败，本版未修复。**
- **Codex A 提交尚未获得实体结果确认。**Claude 的较完整实体成功记录也属于早期版本。
- 滚动可能移动真实鼠标指针；进入转写阶段后需在 Agent 内手动取消。
- 应用仍使用本地 ad-hoc 签名，未经 Apple notarization；Bundle ID 保持 `local.weng.XboxAgentRemote`。

需要 macOS 14 或更新版本、Xbox 手柄及已适配的桌面客户端。解压应用后授予辅助功能权限，并在 JoyCode 中启用控制。

发布附件为应用 ZIP 与 `SHA256SUMS`，将两者放在同一目录后校验：

```bash
shasum -a 256 -c SHA256SUMS
```
