# JoyCode 0.3.15 — Early Preview

Build 27。本版将电量进度整合到原手柄图标，不改变遥控状态机。

## 调整

- 菜单栏保持单个 18 pt 手柄图标，在其底部显示 16 × 2 pt 电量进度线，不增加独立电池图标或宽度。
- 未获得有效电量或手柄断连时保留原手柄图标，不显示问号；详细电量、低电量和充电状态在菜单文字及设置窗口中显示。
- 保留每 30 秒的原生 GameController 刷新，有效读数优先；未知时每 60 秒后台读取蓝牙系统报告。仅当两边均唯一匹配已连接 Xbox 时采用后备读数，失败或歧义仍为未知。
- 暂停遥控后仍更新，菜单区分读数来源。蓝牙报告明确提供的有效 0% 可以显示；未知不当作 0%，100% 不用于推断正在充电。百分比仍是系统／手柄上报的估计值。

本地 215 项测试通过，覆盖后台读取的单任务、取消和重试；单图标渲染样图、安装包构建、签名和 SHA-256 校验通过。远端构建与发布结果见 [Actions](https://github.com/wengych/JoyCode/actions)。

## 验证边界与已知问题

- 0.3.14 曾在连接手柄后显示电量未知；本版实机已识别 Xbox Wireless Controller，显示“约 100% · 充电状态未知”，来源为 macOS 蓝牙报告。**没有验收真实充电变化，也不将 100% 视为正在充电。**
- 实机设置页的同一手柄图标组件进度线正常，辅助功能已恢复并可启用待命。菜单栏单槽布局经过代码和样图验证，实机检查没有覆盖菜单栏截图；本轮不代表全部按键回归通过。
- Codex 原生 X 开始／X 结束、X 开始／B 取消、LB／RB 切换及重入的实体验收来自 **0.3.12**，本版尚未重新进行实体全键验收。
- **Codex 右摇杆滚动的最新实体测试失败，本版未修复。**
- **Codex A 提交尚未获得实体结果确认。**Claude 的较完整实体成功记录也属于早期版本。
- 滚动可能移动真实鼠标指针；进入转写阶段后需在 Agent 内手动取消。
- 应用仍使用本地 ad-hoc 签名，未经 Apple notarization；Bundle ID 保持 `local.weng.XboxAgentRemote`。

需要 macOS 14 或更新版本、Xbox 手柄及已适配的桌面客户端。解压应用后授予辅助功能权限，并在 JoyCode 中启用控制。

发布附件为应用 ZIP 与 `SHA256SUMS`，将两者放在同一目录后校验：

```bash
shasum -a 256 -c SHA256SUMS
```
